# data — 미국 옵션 체인 스냅샷 + 감마 대시보드

CBOE 지연 시세(무료, **15분 지연**)로 미국 지수·ETF·종목 옵션 체인 전체를 1시간 간격으로 받아 쌓고,
SPX·TSLA 월물 기준 딜러 감마 노출(GEX) 대시보드를 **1분 간격**으로 갱신한다.

- 대시보드: https://baseball2000212-coder.github.io/data/ (`docs/index.html`)
  - Settings → Pages → Source 를 **GitHub Actions** 로 한 번 설정해야 한다(`pages.yml`이 배포).
  - 화면은 데이터를 raw.githubusercontent.com 에서 직접 읽는다: 1분 갱신본은 `live` 브랜치(매번 덮어써서 이력 없음),
    매시 스냅샷·일별 추이는 `main`의 `docs/gex/`.
- 원자료 종목: SPX(`_SPX`) · SPY · QQQ · TSLA · AAPL · NVDA · IBIT · VIX(`_VIX`)
  - SPX는 체인이 커서 미결제·거래량이 있고 현재가 ±25% 안의 계약만 저장한다.

## 수집 시각

외부 스케줄러가 `collect.yml`을 `am`·`pm`·`eod` 모드로 실행한다(GitHub 예약은 백업).
시세가 15분 늦으므로 **시장 시각 + 15분에 받고, 파일 이름은 시장 시각**으로 붙인다.

| 모드 | 파일 이름(ET 시장 시각) | 실제 수집 |
|---|---|---|
| am | 0945 · 1045 · 1145 · 1245 | 10:00 · 11:00 · 12:00 · 13:00 |
| pm | 1345 · 1445 · 1545 · 1600(주식 종가) · 1615(옵션 마감) | 14:00 · 15:00 · 16:00 · 16:15 · 16:30 |
| eod | eod — 마감 스냅샷(1615)이 빠진 날만 | 20:00 전후 |

- am·pm 잡은 회차 사이 대기 시간에 SPX·TSLA GEX를 1분마다 다시 계산한다(`live.py`). 시세 자체가 15분 지연이라 그 이상 빨라지지는 않는다.
- SPX 옵션은 야간 거래(GTH, 20:15~09:15 ET = 한국 낮)가 있어 `gth` 모드가 그 시간에도 1분마다 계산한다(잡 하나 최대 5시간 40분, 하루 3번 실행).
  야간에는 지수가 계산되지 않아 CBOE 현재가가 전날 종가에 멈춰 있으므로, 가장 가까운 월물의 풋콜 패리티로 지수를 역산해 현재가로 쓴다.
- 조기 폐장일(13:00)은 am 모드에서 1300 · 1315까지 받는다. 휴장일은 건너뛴다(`us_calendar.py`).
- 이미 받은 회차는 다시 받지 않는다(늦게 뜬 백업 잡이 덮어쓰던 문제 수정).
- CBOE가 묵은 파일을 주면 저장하지 않는다(2026-09-23 하루 종일 전날 밤 파일이 나왔던 문제).
- `quote_et` 열 = 시세가 반영하는 시장 시각(CBOE 파일 시각 − 15분).

**2026-10-29 이전 파일 주의**: 받은 시각으로 이름이 붙어 있어 실제 시장 상태는 이름보다 15분 앞이다
(`_1145` = 11:29 시세, `_0945` = 개장 직후로 그릭스가 0). `_1645`·`_1245`는 백업 잡이 몇 분 늦게 덮어쓴 날이 있다.
2026-09-07(노동절)과 2026-09-23 전체·09-24 오전은 쓸 수 없는 데이터다.

## 파일

```
data/<종목>/<YYYY-MM-DD>/<종목>_<날짜>_<HHMM>.csv.gz   # 2026-10-29부터 gzip (pandas.read_csv가 그대로 읽음)
docs/gex/<종목>.json          # 대시보드용: 그날 회차별 GEX·감마 프로파일·거래량 상위 + 최근 90일 추이
docs/gex/history/<종목>.csv   # 회차별 GEX 요약 전체 기록
```

gzip은 내려받기·체크아웃 용량을 1/4로 줄인다. git이 원래 압축해서 저장하므로 저장소 용량 증가는 비슷하다.

## GEX 계산 (`gex.py`)

- GEX(1% 변동당 달러) = 감마 × 미결제약정 × 100 × 현재가² × 0.01, 콜 +, 풋 −(딜러가 콜 매수·풋 매도라는 통상 가정).
- **월물이 기본**: 미결제약정은 전일 마감 기준이라 당일 생기고 사라지는 0DTE 포지션은 잡히지 않는다.
  SPX는 AM 정산 월물 루트 `SPX`(셋째 금요일 09:30 정산), 위클리·PM 정산은 `SPXW`. TSLA는 셋째 금요일 만기.
- 감마 전환점: 가격 ±12% 범위에서 BS 감마를 다시 계산해 순 GEX가 0을 지나는 가격.
- 콜월·풋월: 월물 행사가별 순 GEX가 가장 큰(+)·작은(−) 행사가. 콜·풋 미결제가 짝으로 쌓인 박스·컨버전 포지션은 서로 상쇄된다.
- 거래량: 오늘 누적 상위와 유입(flow) 상위 두 표. 유입 = 1분 갱신본은 최근 5분, 매시 스냅샷은 직전 회차 대비 늘어난 거래량.
- VIX 옵션은 VIX 선물이 기초자산이라 GEX를 계산하지 않고 거래량만 본다.
- 계산식을 바꾸면 `gex backfill` 워크플로를 수동 실행해 과거 추이를 다시 계산한다.
